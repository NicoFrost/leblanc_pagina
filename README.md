## 🌐 English

A modern, full-featured employee and property management system built with React and Material-UI. Designed to streamline business operations with intuitive interfaces for managing buildings, employees, payroll, finances, and events.

## ✨ Key Features

- **Employee Management** - Complete employee records, contracts, and salary management
- **Property Management** - Track and manage multiple buildings and properties
- **Financial Dashboard** - Income tracking, expenses, invoices, collections, and payment methods
- **Calendar Integration** - Event scheduling and visual timeline management
- **Real-time Reports** - Comprehensive financial and operational reports
- **Authentication System** - Secure login with token-based authentication
- **Responsive Design** - Mobile-friendly interface using Material-UI components

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **State Management**: Redux Toolkit
- **Build Tool**: Vite
- **UI Library**: Material-UI (MUI)
- **Data Grid**: MUI X Data Grid
- **Charts**: MUI X Charts
- **Calendar**: React Big Calendar
- **HTTP Client**: Axios
- **Date Management**: Day.js
- **Notifications**: Notistack

## 📦 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <repository-url>

# Navigate to the project directory
cd Leblanc_Sistema_Frontend

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Available Scripts

```bash
npm run dev      # Start development server with hot module replacement
npm run build    # Build for production
npm run preview  # Preview production build locally
npm run lint     # Run ESLint to check code quality
```

## 📁 Project Structure

```
src/
├── pages/          # Main application pages
├── components/     # Reusable UI components
├── views/          # Feature-specific views
├── layout/         # Layout components
├── hooks/          # Custom React hooks
├── store/          # Redux store configuration
├── api/            # API integration layer

└── CSS/            # Styling
```

## 🎯 Core Modules

- **Buildings** - Property and building management
- **Employees** - Personnel management with contracts
- **Finance** - Comprehensive financial tracking
- **Calendar** - Event scheduling and management
- **Payroll** - Salary and payment processing

## 🔐 Features

- JWT-based authentication
- Protected routes for authenticated users
- Persistent authentication tokens
- Redux state management for app-wide data
